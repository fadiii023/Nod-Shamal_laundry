# Nood Al Shamal 2 Laundry — Frontend

Single-page, responsive bilingual frontend based on the approved visual direction.

## Files
- `index.html` — complete website (HTML + CSS + JavaScript)

## Before publishing
Open `index.html` and edit the `BUSINESS` object near the bottom:
- `phone`
- `whatsapp`
- `maps`
- `hoursEn`
- `hoursAr`

Replace the Unsplash demo images with your real shop photos for the final production version.

## Language
English / العربية switch instantly without page reload. Arabic automatically changes the page to RTL and remembers the user's choice in localStorage.

## GitHub Pages
Upload `index.html` to the repository root and enable GitHub Pages. No build process is required.
